#### OpenCV and SIFT

For the assignments of this course we make use of OpenCV, and at some point we will need SIFT. SIFT is (was?) licensed in such a way that it cannot be delivered as a Python library in the usual way. If you are used to installing packages with pip, then the following command

python3 -m pip install opencv-contrib-python

should give the right results. To test this, you can download and run the following script: [opencv_test.py](https://canvas.uva.nl/courses/56444/files/14954353/download?wrap=1 "opencv_test.py")[Download opencv_test.py](https://canvas.uva.nl/courses/56444/files/14954353/download?download_frd=1)

If running this script produces the following image, then OpenCV with SIFT has been installed correctly.![siftdetect.png](https://canvas.uva.nl/users/184302/files/2389195/preview?verifier=V7nYo0UK8jSzRbEN1i7KNqQb772xLLGis4pK5Rv6)

If it doesn't work, please contact your TA.
