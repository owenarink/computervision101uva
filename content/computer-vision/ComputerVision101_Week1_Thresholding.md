# Thresholding

Source:
- [[CV101_LectureNotes1b]]

Thresholding turns a grayscale image into a binary image:

$$
g = [f > \text{thresh}]
$$

So each output pixel is:

- `1` if its input value is above the threshold
- `0` otherwise

This is a basic segmentation method.
